### Design & Aesthetic

- **Visual Direction:** Minimalist dark mode with deep ocean greens, moody blues, and muted neon accents inspired by the color palette of Joji’s *SMITHEREENS*.
- **Motion & Interaction:** Fluid, interactive HTML5 canvas particle portrait, custom typography, and zero third-party framework bloat.
- **Focus:** Grounded documentation of software prototypes, core computer science foundations, and technical milestones.

---

### Tech Stack

- **Markup & Layout:** Semantic HTML5, Vanilla CSS3 (Custom properties, Flexbox, Grid)
- **Scripting:** Modern JavaScript (ES6+, IntersectionObserver, DOM manipulation)
- **Graphics:** Native 2D Canvas API
- **Hosting:** GitHub Pages
